# Docker Compose

For the independent Mumble-Funk Docker preview, use the maintained
[Docker installation and operations guide](funk/docker.md).

The Docker work is isolated on `feature/docker-install`, based on Simplex v0.2.
The normal Ubuntu setup remains available on `funk-v0.1`. The old upstream
Compose instructions referenced files that are not present in this fork and do
not describe its separate persistent configuration.
